# Prompts

本目录存放工作流中由 agent 直接执行的提示词。它们是仓库里的普通文件：把本仓库作为工作目录打开 agent 后，点名执行即可，不需要复制粘贴到对话框。

## 使用顺序

1. 经历新增、移动、重命名或原始记录发生较大变化时，让 agent 执行[构建内容区索引](构建索引.md)，增量更新 `内容区/索引.md`。
2. 求职或申请产生具体需求时，让 agent 执行 [HTML 简历编写](HTML简历编写.md)，套用 `缓冲区/HTML/templates` 生成响应式网页，并按需由 Edge／Chromium 导出 PDF。

```text
内容区/索引.md（导航，不是事实来源）
        ↓ 定位
内容区原始记录＋内容区/事实资料
        ↓ agent 执行 HTML简历编写.md + 岗位需求
缓冲区/HTML/templates（版式）
        ↓
output/HTMLOutput 中的具体网页与 PDF
```

## 共同原则

- 内容区是唯一的个人事实来源，并保留符合个人习惯的原始记录与复盘。
- 索引只记录链接和少量导航元数据，不保存简历候选表述。
- 已有简历可以作为版式、内容取舍或增量更新基线，Git 可以帮助定位变化；二者都不能代替对当前内容区原文的核验。
- agent 负责筛选、重构和包装，但不得创造事实、数据、职责、成果或技能。
- HTML 模板负责稳定版式；具体简历不得反向污染模板。
- 本项目统一使用 HTML／CSS 排版，不引入 LaTeX；网页视图负责浏览，打印视图负责 A4 分页与 PDF 导出。
- 无法确认的信息不进入正式简历；需要时回到内容区补充，而不是建立新的中间事实层。
- 默认保护隐私；公开版本和直接投递版本应分别生成，不共用含敏感信息的文件。
