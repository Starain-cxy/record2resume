# 项目与科研经历

> 【占位示例】请替换为你自己的经历。项目、竞赛、科研在材料较少时都可以先集中记录在本文件；某段经历的材料变多后，再到 `内容区/工作经历/` 下（或自行新建同类目录）拆成独立目录。

## 记录模板

每段经历按下面的结构写，长度随意，但要能回答这几个问题：

```markdown
## 项目或研究名称

- 时间：2025.03 — 2025.06
- 角色：核心成员 / 负责人 / 研究助理
- 团队：团队规模，以及你负责的部分
- 背景：项目要解决什么问题，为什么值得做

### 我做了什么

如实写你的工作：方法、工具、关键判断、遇到的困难和处理方式。

### 结果

预测精度、效率、覆盖率、规模等可核验结果；没有量化结果就如实写产出，
例如报告、代码、答辩材料、结项材料。

### 我的评价

这段经历重要吗？写简历时应该突出什么？哪里没做好？

### 公开边界

哪些名称、数据、细节不能出现在公开版本中。
```
