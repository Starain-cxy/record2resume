# 实践经历

> 【占位示例】请替换为你自己的经历。社团、学生工作、志愿服务、社会实践等都可以记在这里；材料较多的经历可以拆成独立目录。

## 记录模板

```markdown
## 组织或活动名称

- 时间：2024.09 — 2025.06
- 角色：某部门负责人 / 队员 / 志愿者
- 规模：活动场次、参与人数等可核验信息

### 我做了什么

具体职责、实际执行的事情、遇到的问题和处理方式。

### 说明

这段经历对什么目标有价值；原始记录认为它的优先级如何。
```
