# 内容区

内容区是本项目唯一的个人事实来源，用于保存符合个人习惯的原始记录、复盘、事实资料和公开限制。内容不需要为了迁就简历格式而改写。

内容区会随着经历增加而持续变厚——这是整套系统的资产：记录越多，之后为不同岗位生成简历时能挑的证据越强。

> 本模板仓库的内容区文件都是**占位示例**，请替换成你自己的记录。写完之后，让 agent 执行 [`../缓冲区/Prompts/构建索引.md`](../缓冲区/Prompts/构建索引.md) 生成索引。

当一段经历内容较少时，可以集中记录在同类文件中；当材料足够多时，拆成独立文件夹，并用该文件夹的 `README.md` 说明时间、身份、入口文件和公开边界。

## 目录

| 位置 | 放什么 | 相关约定 |
| --- | --- | --- |
| [`个人信息.md`](个人信息.md) | 姓名、联系方式、社交链接、技能与语言 | 联系方式请标注允许使用的范围 |
| [`事实资料/`](事实资料/README.md) | 成绩、排名、获奖等可核验的稳定事实 | 简历中的数字必须到这里核验 |
| [`工作经历/`](工作经历/README.md) | 实习与正式工作，一段一个目录 | 目录内 `README.md` 说明入口与公开边界 |
| [`项目与科研经历.md`](项目与科研经历.md) | 项目、竞赛、科研 | 材料变多后再拆成独立目录 |
| [`实践经历.md`](实践经历.md) | 社团、学生工作、志愿服务 | 同上 |
| [`assets/`](assets/README.md) | 照片、论文、截图等附件 | 公开前确认哪些附件需要忽略 |

## 索引

[`索引.md`](索引.md) 只用于定位内容区原始材料，记录经历名称、时间、角色、关键词、材料状态和公开限制。索引不是第二份事实库，也不保存“简历候选表述”。

- 新增、移动、重命名或大幅修改经历后，应更新索引。
- 简历编写时先查索引定位材料，再阅读入选经历的原始记录。
- 索引与原始记录冲突时，以原始记录为准，并修正索引。
- 索引没有列出某段经历，不代表该经历不存在；必要时仍应搜索整个内容区。

一些参与的工作项目应尽量同时记录项目本身在做什么、本人贡献如何，以及哪些信息不可公开。成绩、排名和奖项等稳定事实统一放在 `事实资料` 中核验。
