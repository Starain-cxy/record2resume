# assets

存放与经历相关的附件：照片、论文 PDF、截图、证书扫描件、演示文稿等。

## 约定

- 文件名用能一眼看懂的中文或英文，不要用 `IMG_0231.png` 这类默认名称。
- 在对应的内容区文件里用相对链接引用这里，例如 `[证件照](assets/证件照.jpg)`。
- 附件属于**支撑材料**：可以用来说明项目背景和整体结果，但不能仅凭团队材料把某项工作认定为个人贡献。

## 关于公开仓库

附件通常体积大且含个人信息。若要把本仓库公开：

- 在 `.gitignore` 中排除扫描件、证书和论文原文件；
- 或在 `assets/` 下再建 `private/` 目录并整体忽略，只保留 `README.md`。

模板的 `.gitignore` 默认忽略 `output/**/*.pdf` 与 `output/**/*.png`，但没有忽略本目录——请在上传前自行确认。
